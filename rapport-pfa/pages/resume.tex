\chapter*{Résumé}
\addcontentsline{toc}{chapter}{Résumé}

Ce rapport présente le travail réalisé dans le cadre du Projet de Fin d'Année (PFA) de 2\textsuperscript{e} année du cycle ingénieur en Génie Logiciel à l'ISIMS de Sfax. Le stage, effectué à distance au sein de \textbf{SINAPS TEC} (Solutions Innovations For Networks, Applications \& Portable Systems) du 22~juin au 6~septembre~2026, a consisté à concevoir et développer \textbf{Op Support IA}, une solution web et mobile de support client assisté par un agent d'intelligence artificielle.

Le système permet à un client d'ouvrir une conversation, d'obtenir une réponse automatique fondée sur une base de connaissances (approche RAG) et, si besoin, de basculer vers un agent humain en temps réel. Des suggestions d'action rapide accompagnent les réponses IA, tandis que les messages, horodatages, avatars et changements de statut sont persistés. Un espace agent gère la file d'attente des demandes escaladées ; un espace administrateur valide les comptes, consulte l'historique et affiche des indicateurs (volume, résolution IA ou humaine, satisfaction, délai de réponse).

La solution est organisée autour d'un frontend web \textbf{Next.js}, d'un client mobile \textbf{Expo / React Native} et d'un backend \textbf{Node.js / Express}, avec persistance \textbf{MongoDB}, authentification JWT et Google, génération de réponses via \textbf{Gemini} et un retriever local TF-IDF / similarité cosinus. Les deux clients partagent le backend sans être fonctionnellement identiques : le web propose des actions rapides contextuelles, tandis que le mobile propose des suggestions statiques et nécessite une build native pour Google. Des tests automatisés (Jest, Supertest) couvrent l'API, l'authentification, le téléversement, le retriever, les statuts, les horodatages et l'isolation des données de démonstration.

\noindent\textbf{Mots-clés :} support client, agent IA, RAG, Next.js, Express, MongoDB, Socket.io, JWT, PFA.
